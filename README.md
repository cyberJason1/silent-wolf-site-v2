⚙️ 实现原理

    单文件架构：index.html 与 download.html 各自将 HTML / CSS / JavaScript 全部内嵌，无外部 JS、CSS 文件。部署简单，只需要网页文件 + 资源文件夹即可运行。

    CSS：

        @property 注册 --t 主题色，实现角色切换时的平滑过渡

        CSS 变量统一管理主题配色，body[data-t] 切换角色主题色

        perspective + translate3d 实现 3D 圆环

        color-mix() 生成同色系衍生色

        animation-timeline: view() 渐进增强（不支持时降级为普通显示）

        胶片齿孔、取景框、盖章、封条等纯 CSS 绘制

    原生 JavaScript（无第三方库）：

        requestAnimationFrame 驱动圆环旋转与自定义光标

        IntersectionObserver：人物区块进入视口才执行渲染、滚动导航高亮、元素揭示动画

        实现角色弹窗、打字机气泡、角色专属交互、滚动进度条

        Web Audio API 实时合成雨声白噪音与音效，无音频文件依赖

        fetch HEAD 请求检测下载文件是否存在及体积

    资源策略：全部使用相对路径，适配 GitHub Pages，避免 404。

    大视频处理：trailer.mp4 使用 Git LFS 托管，防止 Git 仓库体积膨胀。

    容错机制：所有图片带 onerror 降级——Logo 加载失败则移除、人物模型失败显示角色代号大字、剧照失败显示文字兜底框；视频、音频缺失不影响页面运行。

🧪 本地开发运行

    不要直接双击打开 index.html，会出现路径与文件检测异常。
    （素材下载页的文件体积检测依赖 HTTP 协议，file:// 下不生效。）

终端进入项目根目录执行：
bash

python -m http.server 8000

浏览器访问：http://127.0.0.1:8000

Node 环境亦可：
bash

npx serve .

🚀 GitHub Pages 部署

    将代码推送到 master 分支

    仓库 Settings → Pages

        Source: Deploy from a branch

        Branch: master

        Folder: / (root)

    保存，等待 2–5 分钟部署完成，浏览器硬刷新 Ctrl+Shift+R

📌 已知维护提示

    人物圆环：只有人物区块滚动进入视口才会更新渲染，节省性能。

    图片 404：只会显示兜底文字 / 代号大字，不会造成角色框完全消失。

    视频 mp4：必须由 Git LFS 管理，不建议普通 git 提交。

    下载页文件检测：files/ 中缺失的附件会显示「待上传」并禁用下载按钮，但不会影响页面其余部分；新增附件后需同步更新 download.html 中对应的 href。

    主题色切换：index.html 中角色主题色由 [data-t=xxx]{--c:...} 与角色数据数组 D 共同决定，新增角色需两处同时修改。

    剧透封条：物料卡片上添加 data-seal="1" 即自动生成封条与解锁流程。

    台词写法：角色数据中台词格式为 "马来文|中文字幕"（马来文原声角色）或 "中文"（华语原声角色），由 P() 函数解析。
