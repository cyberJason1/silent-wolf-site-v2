1. 首页 index.html
- 电影级全屏 Hero 视差滚动场景
- 环形 360° 旋转角色动画

3. 人物页 characters.html
- 四大主角独立卡片展示
- 角色形象 + 人设介绍完整呈现
- 支持横向滑动浏览
4. 金句页 quotes.html
- 收录整部 IP 核心台词与氛围感金句
- 电影式引用块样式
